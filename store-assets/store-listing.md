## Full Description (max 16,000 chars)

```
Inspektr is a lightweight, privacy-first developer toolkit designed for web engineers, UI/UX designers, and front-end developers. Inspect visual design attributes, typography, assets, and styling directly on any webpage without having to open complex browser DevTools panels.

─── MODULAR DEVELOPER TOOLKIT ───────────────────

Inspektr is built as an expanding multi-tool suite that centralizes everyday web inspection workflows into one clean, fast interface.

• Tool 1: Font Detector (Active in v0.1.0)
Hover over any element on the page to display an interactive, isolated floating inspector:
- Font family and primary fallback identification
- Automatic source badge detection: Google Fonts, Web Fonts, or System Fonts
- Exact weight (Thin to Black 100-900), size, and style (Normal / Italic)
- Line-height (with calculated ratio) and tracking (letter-spacing)
- Foreground color with interactive visual swatch and hex code
- Quick one-click copy for font family or full CSS declarations
- Direct link to Google Fonts specimen page when available
- Comprehensive "Scan Page Fonts" feature to list and count all fonts across the page

• Upcoming Tools in the Suite:
- Color Picker & WCAG Contrast Checker: Inspect colors, generate palettes, and test contrast accessibility ratios.
- Asset & Image Inspector: Inspect image formats (WebP, AVIF, SVG, PNG), rendered vs. natural dimensions, file weight, and accessibility alt text.
- CSS Custom Properties Extractor: Instantly discover and copy all CSS variables (--vars) defined on the page.
- Box Model & Spacing Inspector: Visualize margins, paddings, gaps, and flex/grid overlays with pixel precision.

─── ZERO-TRACKING & PRIVACY FIRST ───────────────

Inspektr is 100% client-side and requires NO account, NO external servers, and tracks NO personal information:
• Zero Analytics or Telemetry: No tracking libraries or user identifiers.
• Zero Data Collection: Your browsing history and inspected content never leave your machine.
• Least Privilege Permissions: We strictly avoid broad host permissions (<all_urls>). Tools only run when you explicitly click and activate them via activeTab.

Permissions:
• activeTab: Grants transient access to read element styles only when you activate Inspektr on that tab.
• scripting: Loads inspection tools on-demand upon your request.
• storage: Saves your UI preferences and tool toggles locally on your machine.

─── QUICK START ─────────────────────────────────

1. Click the Inspektr icon in your toolbar.
2. Toggle "Font Detector" (or any available tool) ON.
3. Hover over elements to inspect them in real-time.
4. Click to pin the inspector or press ESC to deactivate.

```
